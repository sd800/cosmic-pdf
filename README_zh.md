[English](README.md)

Cosmic PDF 是一款 Chrome PDF 阅读扩展，提供舒适的深浅色外观、清晰的显示和本地文字识别。

## 阅读

直接使用 Cosmic PDF 打开 PDF 链接，或选择本地文件。支持文字查找、页面和目录导航、缩放、向左旋转、全屏、打印和下载原文件。也可切换回 Chrome 阅读器。

阅读器使用独立的扩展页面，避免网页深色模式扩展重复染色。您可以自行选择深色或浅色外观。

## 本地 OCR

支持英文、简体中文和繁体中文扫描件，也能识别中英混合内容。每页识别完成后，即可直接在页面上选择、复制文字。仅在您主动操作后开始识别，不上传或修改 PDF。

## 自定义

设置页提供外观、工具栏布局、1×–6× 显示清晰度、可选锐化、初始缩放、页面间距、缩略图、文档链接、外部链接捕获和 OCR 选项。界面支持英文和简体中文。

## 安装

需要 Chrome 128 或更高版本。

1. 打开 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本仓库的 `extension` 目录。
3. 可将 **Cosmic PDF** 固定在工具栏，以便打开本地文件。阅读器和扩展选项菜单均可进入设置页。

若希望自动接管 `file://` PDF 链接，请在 Chrome 扩展详情中开启“允许访问文件网址”，然后重新打开扩展或设置页。选择文件或拖放文件无需该权限。

自动打开支持独立标签页中的普通 HTTP(S) PDF 响应，以及已授权的本地 PDF 链接。暂不自动替换嵌入式阅读器、通过 POST 生成的文档或不透明的 blob 链接。标记为附件的文件仍正常下载。部分需要登录或一次性链接的文件可能需要使用 Chrome 阅读器或本地副本。本阅读器的文件安全读取上限为 64 MB。

## 隐私与安全

文档和识别结果仅保留在当前阅读器中，关闭后丢弃，只持久保存偏好设置。PDF 脚本、表单执行、编辑和远程文档资源均被禁用，不改变原文件。任何解析器都无法保证抵御所有畸形文件，请保持 Chrome 和扩展更新。
